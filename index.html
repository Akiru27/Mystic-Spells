☁️ PC・スマホのデータ共有

クラウド設定を行うと、購入記録を両方の端末で共有できます。

未設定：この端末内の購入履歴を表示しています。

同じProject URLと公開用キーをPC・スマホ両方に設定してください。Supabase側でテーブルとアクセス権限の設定が必要です。service_roleなどの秘密鍵は絶対に入力しないでください。

Supabase側のテーブル設定

SupabaseのSQL Editorで実行してください。この簡易設定では、アプリを使える人が購入履歴を閲覧・追加できます。機密情報は保存しないでください。

create table if not exists public.purchase_records (
  id text primary key,
  purchased_at timestamptz not null,
  items jsonb not null
);

alter table public.purchase_records enable row level security;

create policy "Public can read purchase records"
on public.purchase_records for select to anon using (true);

create policy "Public can insert purchase records"
on public.purchase_records for insert to anon with check (true);
